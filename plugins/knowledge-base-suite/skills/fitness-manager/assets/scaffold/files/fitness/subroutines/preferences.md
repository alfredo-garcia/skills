# subroutines preferences

- Todo ejercicio nuevo de una sub-rutina debe respetar program/<usuario>.yaml → constraints.
- Progresar de poco en poco: repeticiones o segundos antes que banda o variante.
- Ejercicios por lados: siempre un solo ejercicio que hace los dos lados en la misma serie, nunca uno por lado.
- Una dosis distinta es otra sub-rutina: las rutinas no cambian dosis.
